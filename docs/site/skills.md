## Design and review

Design specifications adaptively and audit existing documents with fresh-context reviewers.

- [Design](/skills/egm-design) `/egm-design`

  Adaptive architectural design from an idea or existing document through independent review and human approval.

- [Review](/skills/egm-review) `/egm-review`

  Independently review an existing design with risk-based fresh-context coverage, read-only unless edits are authorized.

## Work with code

Document a codebase for a demonstrated reader need and check whether code matches checked-in designs.

- [Document a codebase](/skills/egm-bootstrap) `/egm-bootstrap`

  Create or update targeted architectural documentation without mirroring every directory or symbol.

- [Check for drift](/skills/egm-drift-report) `/egm-drift-report`

  Compare checked-in documents with the current source code.
