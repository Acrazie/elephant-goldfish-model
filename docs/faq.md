# Frequently asked questions

## Do I have to run every phase?

No. Start `egm-design` explicitly with your current idea, architecture or document.
It performs only the missing work, within the agreed mandate. Draft-only requests
exclude review. `egm-review` is available for review alone.

## How many documents does EGM create?

Update a relevant existing design or maintain one canonical design per change.
Intermediate findings are temporary. A separate report is an explicit export.
Targeted bootstrap documentation is optional, not a prerequisite to design.

## Does EGM implement code?

No. Final approval concerns the design, not production changes or publication.
Leave EGM and authorize implementation separately.

## What happens if independent review is unavailable?

The review is incomplete, not successful. An inline critique is not an independent
Goldfish review. See [host limitations](harnesses.md) and the
[review procedure](../resources/review-workflow.md).

## Are old command names supported?

No. Use the four commands in the [workflow guide](getting_started.md). Existing
user files remain untouched and may be explicitly selected as context.
